The Soft Studio

Warm minimalism: near-neutral warm surfaces, generous whitespace, hairline rules, soft large-radius shadows, and exactly one accent — a restrained clay reserved for what matters (the chase, the earned badge, the active filter). The cards carry all the color; the room around them stays calm so the collection reads like work hung in a small studio. It fits because the chronicle's dignity survives best when the interface says the least.
